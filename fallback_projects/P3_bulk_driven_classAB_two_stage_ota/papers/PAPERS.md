# Papers for Project 3 (0.6 V bulk-driven class-AB two-stage OTA)

The cloud machine could not download PDFs, so this file gives citations, DOIs and open-access links.

## Base paper
- **A. Ballo, A. D. Grasso, S. Pennisi, "A 0.6 V Bulk-Driven Class-AB Two-Stage OTA with Non-Tailed Differential Pair,"**
  *J. Low Power Electron. Appl.* 13(2):24, 28 Mar 2023. doi:10.3390/jlpea13020024. **OA:** https://www.mdpi.com/2079-9268/13/2/24
  180 nm, 0.6 V, CL = 150 pF, IBias = 180 nA. Bulk-driven non-tailed pair M1–M2, diode loads with cross-coupled positive feedback
  (α = 0.83), current gain β = 15, Miller compensation through the current buffer, quasi-floating-gate class-AB second stage
  (RBATT 1 MΩ, CBATT 800 fF). Reported: 3.29 µW, 64.8 dB, GBW 357 kHz, PM 67.6°, **SR +0.17 / −6.61 V/µs**, 1.3 µV/√Hz, 1329 µm².
  Temperatures checked in the paper: −10, 27 and 85 °C only.
