# Papers for Project 2 (single-stage OTA / differential amplifier with resistive local CMFB)

The cloud machine could not download PDFs, so this file gives citations, DOIs and open-access links.

## Base paper
- **J. Ramírez-Angulo, A. Díaz-Armendáriz, J. E. Molinar-Solís, A. Díaz-Sánchez, J. Huerta-Chua, "Simple Technique to Improve
  Essentially the Performance of One-Stage Op-Amps in Deep Submicrometer CMOS Technologies,"** *J. Low Power Electron. Appl.*
  13(1):4, 4 Jan 2023. doi:10.3390/jlpea13010004. **OA:** https://www.mdpi.com/2079-9268/13/1/4
  Conventional symmetrical OTA vs the same OTA with resistive local common-mode feedback (RLCMFB), simulated at 22/45/90/180 nm
  with generic models. All devices W = 10 µm, L = 2Lmin, IB = 2.5 µA, CL = 2 pF; at 90 nm R = 300 kΩ, Rs = 3 kΩ, ±0.45 V.
  Reported at 90 nm: conventional 32.9 dB / 4.8 MHz / PM 89° / SR +2.4 −2 V/µs; RLCMFB 60.8 dB / 38.4 MHz / PM 68° / SR +42.1 −22.3 V/µs.
